# Tristar Motors website guide

## Client side

[Open the website](https://tristarmotors-ke.onrender.com/)

This is the public page customers use to browse cars and contact Tristar Motors.

## Admin side

[Open the admin page](https://tristarmotors-ke.onrender.com/#/admin)

Sign in with:

- **Administrator:** Allan
- **Password:** `AllanTristar@123`

### Manage cars

- Select **Add a car** to enter vehicle details, add pictures, and save a listing.
- Select **Edit** beside a car to update its details or pictures.
- Use the availability menu to mark a car **Available**, **Pending**, or **Sold**.
- Select **Remove** to delete a listing.
- Leave the price blank to keep a listing hidden from the public website.

Photos uploaded from the admin page are converted to WebP automatically.

### Customer inquiries

Select **Inquiries** to view customer messages and requests.

### Change the password

Select **Change password** in the admin page. Enter the current password and a new password of at least 12 characters. You’ll need to sign in again with the new password.
